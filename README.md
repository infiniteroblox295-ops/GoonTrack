# GoonTrack

**Roblox Account Information Tracker**

> This project can fetch roblox account information such as **Creation Date, RAP, Email Verified, etc...** simply by entering the target Roblox username.

**List of Features:**
- ✔️ Full Body Avatar
- ✔️ Creation Date
- ✔️ Description
- ✔️ Display Name
- ✔️ Email Verified (boolean)
- ✔️ Followers Count
- ✔️ Following Count
- ✔️ Groups Joined
- ✔️ Groups Owned
- ✔️ Banned (boolean)
- ✔️ Last Location
- ✔️ Premium (boolean)
- ✔️ RAP
- ✔️ User ID
- ✔️ Username

**Usage:**
```
localhost:5000/user/{USERNAME}
```
